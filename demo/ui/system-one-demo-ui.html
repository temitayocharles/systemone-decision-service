How this system stays honest
  • No provider, no guess. Misconfigured or unreachable backend → error, never a fabricated answer.
  • Too few examples, no fake fit. Calibration needs 20+ labeled examples or it refuses.
  • Only measured providers win. Empirical routing rejects benchmark records without provenance.
  • Your code owns every action. The model supplies probabilities; thresholds and side effects are yours.
  • Every number is auditable. Route, provider, model, tokens, and latency come back in each response.
